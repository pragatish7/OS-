# Installation of Windows Operating System

## Requirements

* Computer/Laptop
* USB drive (minimum 8 GB)
* Windows ISO image
* Bootable media creation tool
* Internet connection

## Commands Used

### 1. Display Windows Version

```cmd
winver
```

### 2. Display System Information

```cmd
systeminfo
```

### 3. Display Computer Name

```cmd
hostname
```

### 4. Display Disk Information

```cmd
diskpart
list disk
exit
```

### 5. Check Windows Activation Status

```cmd
slmgr /xpr
```

### 6. Display IP Configuration

```cmd
ipconfig
```

## Result

The Windows Operating System was successfully installed and configured on the computer. The system commands were used to confirm the operating system, hardware, disk, activation, and network configuration.
